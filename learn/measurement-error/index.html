Measurement, Error & Data Analysis測定・誤差・データ解析の基礎

As a number, $9.8$ and $9.80000$ are equal. As measurement reports they are completely different claims: the second asserts a hundred-thousand-fold better knowledge, and writing it without grounds is, scientifically, a lie. Behind this gap lies everything this page covers: every measurement carries an uncertainty, and the experimenter's job is to estimate it, report it, and carry it through calculations honestly. Four questions, in the order they arise in practice: what kinds of error exist (§00); how many digits a measured number may claim (§01); how uncertainties combine when measurements enter a formula (§02); and how far repetition can push the uncertainty down (§03). Each section has an interactive demo.数としては $9.8$ と $9.80000$ は等しい。だが測定の報告としては全く別の主張である。後者は10万倍精密に知っていると主張しており、根拠なくそう書けば、科学的には嘘になる。この差の背後に、本ページで扱うことのすべてがある。あらゆる測定値は不確かさを伴い、実験者の仕事はそれを正直に見積もり、報告し、計算の中まで持ち運ぶことだ。実務で現れる順に、4つの問いを扱う：誤差にはどんな種類があるか（§00）、測定値は何桁まで主張してよいか（§01）、測定値を式に通すと不確かさはどう合成されるか（§02）、繰り返し測定で不確かさをどこまで減らせるか（§03）。各節に操作できるデモを添えた。

00 — What is the error made of?00 — 誤差は何でできているのか

Systematic vs random: accuracy vs precision系統誤差と偶然誤差：正確さと精密さ

Why classify errors at all? Because the two kinds respond to completely different remedies. A systematic error shifts every reading the same way (a mis-zeroed scale, an un-subtracted baseline): it limits accuracy, how close the average sits to the true value. A random error scatters readings unpredictably (electronic noise, counting statistics): it limits precision, how tightly the readings cluster. Averaging beats down random error but is powerless against a systematic one.なぜ誤差をわざわざ分類するのか。種類によって対処法がまるで違うからだ。測定誤差は本質的に異なる2種類に分かれる。系統誤差はすべての測定値を同じ向きにずらす（ゼロ点のずれ、引き残したベースラインなど）：これは正確さ（accuracy）、すなわち平均が真値にどれだけ近いかを制限する。偶然誤差は測定値を予測できない形でばらつかせる（電子ノイズ、計数統計など）：これは精密さ（precision）、すなわち測定値がどれだけ密に集まるかを制限する。平均をとれば偶然誤差は小さくできるが、系統誤差には無力である。

01 — How many digits can you trust?01 — 何桁まで信じてよいのか

Significant figures有効数字

As §00 showed, every measured value contains error, so writing digits below the doubtful one is meaningless; they are just garbage. Ask for the circumference of a circle of diameter 30.0 mm and a calculator happily returns 94.2477796077 mm. But if that last diameter digit is uncertain, the true diameter sits somewhere in 29.95–30.05 mm, and the circumference in 94.09–94.40 mm: already the third digit is in doubt. Everything after it is noise. So scientists adopt a shared convention for how many digits to keep.§00 で見たとおり、あらゆる測定値は誤差を含む。だとすれば、怪しい桁より下を書いても意味がない。ただのデタラメな数字だ。直径 30.0 mm の円の円周を尋ねると、電卓は平気で 94.2477796077 mm と返す。だが最後の直径の桁が不確かなら、真の直径は 29.95〜30.05 mm のどこかにあり、円周は 94.09〜94.40 mm：すでに3桁目が怪しい。それ以降はただのノイズだ。そこで科学者は、何桁残すかの共通ルールを採用する。

The basic convention表記の基本

When you read an instrument you can usually estimate to about 1/10 of the smallest division by eye. That last estimated digit is uncertain, but it still carries real information, so it is worth recording; anything below it is pure waste. Hence the universal rule:測定器を読むとき、ふつう最小目盛の1/10くらいまで目分量で読み取れる。その最後の桁は不確かだが、おおよそ正しい情報を含むので記録する価値がある。それより下の桁は全くの無駄だ。そこで普遍的なルール：

”The last written digit is informative, but suspect it!”「記載された数値の最後の桁は参考になるが、かなり怪しいと疑え！」

Then how many digits you write tells the reader how far the value can be trusted. A problem arises only above the decimal point: in 123000, are the trailing zeros real or just placeholders? Scientific notation removes the ambiguity:こうすれば、何桁書くかで「どこまで信用できるか」を読み手に伝えられる。困るのは小数点より上の桁だけだ：123000 の末尾のゼロは有効なのか位取りなのか分からない。指数表記（科学的表記法）がこの曖昧さを取り除く：

$$1.23\times10^{5}\ \text{(3 s.f.)},\quad 1.230\times10^{5}\ \text{(4 s.f.)},\quad 1.2300\times10^{5}\ \text{(5 s.f.)}$$

It works for small numbers too: $0.000456 = 4.56\times10^{-4}$, with no need to count zeros. The number of significant figures is counted from the first non-zero digit through the doubtful last digit (leading zeros never count). So $1.230\times10^{5}$ has 4 significant figures; $0.000456$ has 3 (the digits 456).小さな数にも使える：$0.000456 = 4.56\times10^{-4}$、ゼロを数えなくてよい。有効数字の桁数は、最初の非ゼロ数字から怪しい最後の桁まで数える（先頭のゼロは数えない）。よって $1.230\times10^{5}$ は4桁、$0.000456$ は3桁（456 の部分）である。

The rules for arithmetic四則演算の作法

Addition / subtraction: line the numbers up by place value; the answer can only be trusted down to the highest last-trustworthy place among the inputs, so keep the fewest decimal places. Multiplication / division: place value is irrelevant; only the count of significant figures matters, so the answer keeps the fewest significant figures. In all cases, round just once, at the end. For example:加算・減算：位を揃えて並べる。結果は入力のうち最後の信頼桁が最も高い位までしか信用できないので、最小の小数位に合わせる。乗算・除算：位は関係なく、有効数字の桁数だけが効くので、結果は最小の有効数字に合わせる。いずれも丸めは最後に1回だけ。例えば：

$$12.34 + 1.1 = 13.4\ \ (\text{fewest dp}=1),\qquad 12.34 \times 1.1 = 14\ \ (\text{fewest s.f.}=2)$$

Keep a trailing zero when the rule produces one: it marks where the doubt sits ($1.1+2.4=3.5$; a carry gives $9.9+0.2=10.1$). And subtraction can be brutal: $1.2345-1.2300=0.0045$ collapses 5- and 6-figure inputs into a 2-figure answer (catastrophic cancellation). Round only the final answer.ルールの結果として末尾に 0 が出たら残す。そこに疑いがあることを示す（$1.1+2.4=3.5$、繰り上がりで $9.9+0.2=10.1$）。引き算は厳しく、$1.2345-1.2300=0.0045$ は5桁・6桁の入力を2桁の答えに変えてしまう（桁落ち）。丸めは最終結果だけ。

One caveat: constants don't limit the count. Numbers that aren't measured (mathematical constants ($\pi$, $e$), plain integers like the "2" in $2\pi r$, exact counts, and defined values such as the speed of light $c=299{,}792{,}458$ m/s) carry infinitely many significant figures and never cap the result. In practice you only need to carry one or two guard digits beyond the target precision; there is no point typing a 12-digit $\pi$ into a calculator.1つだけ注意：定数は桁数を制限しない。測定値でない数（数学定数（$\pi$, $e$）、$2\pi r$ の「2」のようなただの整数、数えられる個数、そして光速 $c=299{,}792{,}458$ m/s のような定義値）は有効数字を無限桁持ち、結果の桁数を制限しない。実用上は目標精度より1〜2桁だけ余分に持てば十分で、$\pi$ を12桁も電卓に打ち込む意味はない。

Where these rules come fromこの作法はどこから来るのか

Significant-figure rules are really just error propagation done in your head: a handy shortcut for a quick sanity check, but a crude one (they assume the last digit is uncertain by $\pm0.5$ and say nothing about $\sqrt{\ }$, $\ln$ or $\sin$). When precision matters, modern practice quotes the uncertainty explicitly instead. Both where these rules come from and when they break have the same answer: error propagation, which is the subject of §02.有効数字のルールとは、つまるところ頭の中でやる誤差伝播だ。手早い確認には便利だが粗い近道で（末尾桁の誤差を $\pm0.5$ と仮定し、$\sqrt{\ }$・$\ln$・$\sin$ には何も言えない）、精度が要るときは現代の作法のように不確かさを明示的に併記する。この作法がどこから来て、いつ破綻するのか。その答えはどちらも誤差伝播であり、§02 の主題である。

02 — How does uncertainty travel through a formula?02 — 不確かさは式の中をどう伝わるのか

Propagation of uncertainty誤差の伝播

§01 dealt with a single measured number, but the quantity you actually want is rarely the one you measure. Usually you compute it from several other measurements as an indirect measurement $X=f(a,b,c)$, and you must carry the errors of $a,b,c$ through to $X$. For a simple $f$ you could just nudge each input within its error and read off the largest and smallest $X$ (exactly what the Monte-Carlo panel below does). The general shortcut comes from a first-order Taylor expansion:§01 で扱ったのは1つの測定値だった。だが、本当に知りたい量を直接測れることはむしろまれで、多くは複数の測定から間接測定 $X=f(a,b,c)$ として計算するため、$a,b,c$ の誤差を $X$ まで運ぶ必要がある。$f$ が単純なら、各入力を誤差の範囲で動かして $X$ の最大・最小を読めばよい（下のモンテカルロパネルがまさにそれだ）。一般的な近道は1次のテイラー展開から得られる：

$$f(a+\Delta a,\,b+\Delta b,\,c+\Delta c)\simeq f(a,b,c)+\frac{\partial f}{\partial a}\Delta a+\frac{\partial f}{\partial b}\Delta b+\frac{\partial f}{\partial c}\Delta c$$

Statistical case (quadrature): the default. When the errors are independent and random, they more often partly cancel than fully reinforce, so the honest, realistic estimate adds them in quadrature. This is the uncertainty used throughout this page:統計的な場合（二乗和）：基本。誤差が独立でランダムなら、完全に強め合うより部分的に打ち消し合うことの方が多いので、正直で現実的な見積もりは二乗和で合成する。本ページで通して使う不確かさだ：

$$\delta f=\sqrt{\sum_i\left(\frac{\partial f}{\partial x_i}\right)^{\!2}\delta x_i^{\,2}}$$

From this rule the same handy shortcuts fall out: for sums and differences the absolute uncertainties combine; for products, quotients and powers the relative ones do (a power $x^n$ multiplies the relative uncertainty by $|n|$, a logarithm turns a relative error into an absolute one). (If you ever need a guaranteed upper bound rather than the realistic estimate, the conservative "worst-case" version is in the note below.)この規則から、同じ便利な近道が出てくる：和・差では絶対不確かさが、積・商・べき乗では相対不確かさが合成される（べき乗 $x^n$ は相対不確かさを $|n|$ 倍し、対数は相対誤差を絶対誤差に変える）。（現実的な見積もりではなく保証された上限が欲しいときのために、保守的な「最悪値」版を下の注に載せた。）

Why independent errors add in quadrature, while correlated ones add linearlyなぜ独立なら二乗和、相関があれば線形和になるのか

Write the deviation of the $i$-th result from the Taylor expansion, then square it and average over $N$ measurements. The square gives square terms plus cross terms:$i$ 番目の結果のずれをテイラー展開で書き、2乗して $N$ 回の測定で平均する。2乗すると平方項と交差項が出る：

$$\sigma_X^2=\sum_i\left(\frac{\partial f}{\partial x_i}\right)^{\!2}\sigma_{x_i}^2\;+\;\underbrace{\sum_{i\neq j}\frac{\partial f}{\partial x_i}\frac{\partial f}{\partial x_j}\,\sigma_{x_i x_j}}_{\text{cross terms (covariances)}}$$

Square terms are always positive and never cancel. The cross terms carry the covariances $\sigma_{x_i x_j}$. If the variables are independent and random, each cross term is as likely positive as negative, so they sum to zero (more perfectly as $N$ grows), leaving the clean quadrature sum of variances. If instead the variables are fully correlated (an error in one always drags the others the same way), the cross terms survive and reinforce, and the root-sum collapses back into the linear worst-case sum. Real cases lie between these limits, which is why covariances must be kept when measurements are not independent (e.g. two masses read off the same mis-calibrated balance).平方項は常に正で打ち消さない。交差項は共分散 $\sigma_{x_i x_j}$ を担う。変数が独立でランダムなら、各交差項は正にも負にも等しくなりやすく、合計は0に近づく（$N$ が大きいほど完全に）。こうして二乗和だけが残る。逆に変数が完全に相関していれば（一方の誤差が常に他方を同じ向きに引きずる）、交差項は生き残って強め合い、平方和は線形の最悪値和に戻る。実際はこの中間にあり、だから測定が独立でないとき（同じ狂った天秤で読んだ2つの質量など）は共分散を残す必要がある。

That fully-correlated limit is exactly the worst-case (maximum) error: assume every error conspires to push $X$ the same way, take absolute values so the terms always reinforce, and you get the conservative upper boundこの完全相関の極限こそが最悪値（最大誤差）である：すべての誤差が $X$ を同じ向きに押すよう共謀すると仮定し、項が必ず強め合うように絶対値をとると、保守的な上限が得られる：

$$\Delta X=\left|\frac{\partial f}{\partial a}\right|\Delta a+\left|\frac{\partial f}{\partial b}\right|\Delta b+\left|\frac{\partial f}{\partial c}\right|\Delta c$$

It over-estimates the realistic spread, so quote it only when you need a guaranteed limit; otherwise use the quadrature result above.これは現実的なばらつきを過大評価するので、保証された限界が要るときだけ使い、それ以外は上の二乗和を用いる。

For near-linear formulas the analytic and Monte-Carlo values agree: two independent routes to the same uncertainty. Quadrature means a small uncertainty contributes almost nothing once a larger one is present, so effort is best spent on the dominant term.ほぼ線形な式では解析式とモンテカルロの値は一致する。同じ不確かさへの独立な2つの経路だ。二乗和では、大きな不確かさがあると小さなものはほとんど効かないので、支配的な項に労力を割くのが最善である。

Why isn't the histogram always a bell curve?ヒストグラムが必ずしも釣鐘型にならないのは？

The analytic formula is a first-order (linear) approximation: it replaces $f$ by its tangent over the $\pm\delta$ range and assumes the result is Gaussian. For a nonlinear $f$ (try x*sin(y)), pushing the uncertainties up makes the true (Monte-Carlo) distribution skewed and non-normal, and the green Normal curve no longer fits. The effect is strongest where the slope $\partial f/\partial x_i$ nearly vanishes (e.g. $y$ near $\pi/2$ for $\sin y$), and where $f$ is a product of comparable random factors. Unlike a sum of many terms, a 2-variable $f$ has no reason to be normal (no Central Limit Theorem here). Shrink the $\delta$ sliders and the linear approximation recovers: the histogram tightens back onto the green curve and the agreement rises.解析式は一次（線形）近似で、$\pm\delta$ の範囲で $f$ を接線に置き換え、結果がガウス分布だと仮定している。非線形な $f$（例：x*sin(y)）で不確かさを大きくすると、真の（モンテカルロ）分布は歪んで非正規になり、緑の正規曲線は合わなくなる。効果が最も強いのは、傾き $\partial f/\partial x_i$ がほぼ消える点（$\sin y$ なら $y\approx\pi/2$ 付近）や、同程度の大きさの確率変数どうしの積になっている場合だ。多数の項の和と違い、2変数の $f$ が正規分布になる理由はない（ここでは中心極限定理は効かない）。$\delta$ スライダーを小さくすると線形近似が回復し、ヒストグラムは緑曲線に締まり、一致度も上がる。

Pre-computed: products, powers and logarithmsあらかじめ計算：積・べき乗・対数

Doing the partial derivatives every time is tedious, so pre-compute the common form. Most physics formulas look like $X=a^{l}b^{m}c^{n}$. Feed it through the propagation formula and divide by $|X|$, and the absolute mess collapses into a tidy sum of relative errors:毎回偏微分するのは面倒なので、よく出る形をあらかじめ計算しておく。多くの物理量は $X=a^{l}b^{m}c^{n}$ の形だ。これを伝播式に通して $|X|$ で割ると、絶対誤差の煩雑さが相対誤差のすっきりした和にまとまる：

$$\frac{\Delta X}{|X|}=|l|\frac{\Delta a}{|a|}+|m|\frac{\Delta b}{|b|}+|n|\frac{\Delta c}{|c|}$$

So a squared quantity contributes twice its relative error, a square root half, and it makes no difference whether a factor multiplies or divides. Logarithms are the other handy case: for $X=\ln a$ the propagation formula gives $\Delta X=\Delta a/|a|$, so a relative error becomes an absolute one. (These are exactly the §01 shortcuts, now derived.)2乗の量は相対誤差の2倍、平方根なら半分を寄与し、掛けるか割るかは関係ない。対数はもう一つの便利な例で、$X=\ln a$ なら伝播式から $\Delta X=\Delta a/|a|$。相対誤差が絶対誤差になる。（これらは §01 の近道を、いま導出したものだ。）

Reference: propagation formulas for the basic operations早見：基本演算の誤差伝播公式

Addition / subtraction: absolute uncertainties combine (this is why you keep the fewest decimal places):加算・減算：絶対不確かさが合成される（だから最小の小数位に合わせる）：

$$z=x\pm y\;\Rightarrow\;\delta z=\sqrt{(\delta x)^2+(\delta y)^2}$$

Multiplication / division: relative uncertainties combine (this is why you keep the fewest significant figures):乗算・除算：相対不確かさが合成される（だから最小の有効数字に合わせる）：

$$z=xy\ \text{or}\ \frac{x}{y}\;\Rightarrow\;\frac{\delta z}{|z|}=\sqrt{\left(\frac{\delta x}{x}\right)^2+\left(\frac{\delta y}{y}\right)^2}$$

Powers and roots: the relative uncertainty is multiplied by the exponent:べき乗・根：相対不確かさは指数倍される：

$$z=x^{n}\;\Rightarrow\;\frac{\delta z}{|z|}=|n|\,\frac{\delta x}{|x|}$$

Scaling, logarithm and exponential (handy special cases):定数倍・対数・指数（よく使う特殊例）：

$$z=c\,x\Rightarrow\delta z=|c|\,\delta x,\qquad z=\ln x\Rightarrow\delta z=\frac{\delta x}{|x|},\qquad z=e^{x}\Rightarrow\frac{\delta z}{|z|}=\delta x$$

Every line is the single general rule $(\delta z)^2=\sum_i(\partial z/\partial x_i)^2(\delta x_i)^2$ evaluated for that function: the quadrature (independent/random) version. For a worst-case bound, drop the squares and add the absolute terms instead.どの行も、一般則 $(\delta z)^2=\sum_i(\partial z/\partial x_i)^2(\delta x_i)^2$ を各関数について評価したもの。二乗和（独立・ランダム）版である。最悪値の上限が欲しいなら、2乗を外して絶対値の項をそのまま足せばよい。

Worked example: Beer's law実例：ビールの法則

The molar absorptivity from Beer's law is $\varepsilon=A/(l\,c)$. With $A=0.172807\,(\pm0.000008)$, $l=1.0\,(\pm0.1)$ cm, and $c=13.7\,(\pm0.3)$ mol/L, the relative errors combine in quadrature:ビールの法則によるモル吸光係数は $\varepsilon=A/(l\,c)$。$A=0.172807\,(\pm0.000008)$、$l=1.0\,(\pm0.1)$ cm、$c=13.7\,(\pm0.3)$ mol/L とすると、相対誤差が二乗和で合成される：

$$\frac{\delta\varepsilon}{\varepsilon}=\sqrt{\left(\frac{0.000008}{0.172807}\right)^{\!2}+\left(\frac{0.1}{1.0}\right)^{\!2}+\left(\frac{0.3}{13.7}\right)^{\!2}}\approx0.102\;\Rightarrow\;\varepsilon=0.013\pm0.001$$

The $\pm0.1$ cm path length dominates entirely (a 10 % relative error), so a better cuvette, not a better spectrophotometer, is what would improve the result. Load the ε = A/(l·c) preset above (with $x=A$, $y=l$, $z=c$) and the variance-share bars show exactly this.$\pm0.1$ cm の光路長が完全に支配し（相対誤差10%）、結果を改善するのは分光光度計ではなく良いセル（キュベット）だと分かる。上の ε = A/(l·c) プリセット（$x=A$, $y=l$, $z=c$）を読み込むと、分散寄与の棒がまさにこれを示す。

How to write a propagated result伝播した結果の書き方

Once you have an uncertainty, don't quote it to many digits: it only needs to show where the doubt sits. Keep the error to its top significant figure (a second figure if it rounds to a leading 1), quote the value down to the error's last digit, and round only at the end. For readability prefer the factored form $(1.23\pm0.05)\times10^{5}$ over $123000\pm5000$, and always quote the uncertainty so the next calculation can propagate it. (The fuller reporting conventions are collected in §03e.)不確かさが求まったら、桁を長々と書かない。どこに疑いがあるかを示せれば十分だ。誤差は最上位の1桁に丸め（先頭が1に丸まる場合は2桁）、測定値は誤差の末尾と同じ位まで書き、丸めは最後だけ。読みやすさのため $123000\pm5000$ より $(1.23\pm0.05)\times10^{5}$ の括り出し表記が望ましく、次の計算で伝播できるよう不確かさは必ず併記する。（より詳しい報告の作法は §03e にまとめてある。）

$$\delta=0.0732\to0.07:\ \ 3.54\pm0.07\qquad \delta=0.00953\to0.010:\ \ 3.537\pm0.010\qquad \delta=0.127\to0.13:\ \ 3.54\pm0.13$$

Cautions注意点

Propagation assumes each relative uncertainty is small (the linear approximation; see the histogram note above). If you can get the uncertainty directly, by repeating the whole experiment and watching the scatter, prefer that to propagating (§03). And remember: a calculation never reduces uncertainty; only better measurements do. In complex cases the estimate can also go wrong through unsuspected covariances, a mis-specified model, or arithmetic slips.伝播は各相対誤差が小さいことを前提とする（線形近似。上のヒストグラム注記を参照）。実験全体を繰り返してばらつきから直接不確かさを得られるなら、伝播よりそちらを優先する（§03）。そして忘れてはいけない：計算で不確かさは決して減らない。減らせるのはより良い測定だけだ。複雑な場合には、見落とした共分散、モデルの誤設定、計算ミスによって見積もりが狂うこともある。

When the same quantity is measured repeatedly同じ量を繰り返し測ると

The worst-case sum is right when you accumulate independent pieces, for example measuring a length in several segments and adding them. But adding up repeated measurements of the same quantity to form an average is different: those readings scatter both above and below, so their random errors tend to cancel rather than pile up. (A systematic error does accumulate, but dividing by $n$ brings it back to one reading's worth.) How fast the random part shrinks with the number of measurements is the subject of the next module.最悪値の和が正しいのは、独立な部分を蓄積するとき、たとえば長さを何区間かに分けて測り足し合わせる場合だ。しかし同じ量の繰り返し測定を足して平均をとるのは別物だ：それらの測定値は上にも下にもばらつくので、偶然誤差は積み重なるより打ち消し合う傾向がある。（系統誤差は蓄積するが、$n$ で割れば1回分の測定に戻る。）偶然誤差が測定回数とともにどれだけ速く縮むかが、次のモジュールの主題である。

03 — Does measuring again actually help?03 — 繰り返し測れば誤差は減るのか

Statistical processing of measurements測定値の統計処理

Propagation only describes how existing uncertainties combine; a calculation never makes them smaller. The one operation that actually shrinks a random error is more data: measure the same quantity repeatedly and average. The readings scatter around the true value, so the average should land near it, but how near, and how should that confidence be reported? That is the question of this module. (Strictly we never observe the true value itself, only error-laden readings, and for some phenomena, such as quantum measurements, no single true value even exists. We will nonetheless keep the intuitive picture that a true value is out there.)伝播は、すでにある不確かさがどう合成されるかを記述するだけで、計算によって不確かさが減ることはない。偶然誤差を実際に減らせる唯一の操作はデータを増やすこと：同じ量を繰り返し測り、平均をとることだ。測定値は真の値のまわりにばらつくから、平均は真の値の近くに落ちるはずである。だがどれくらい近いのか、その確からしさをどう報告すればよいのか。これが本モジュールの主題だ。（厳密には我々は真の値そのものを観測できず、誤差を含む測定値しか得られない。量子測定のように、そもそも単一の真の値が存在しない対象もある。ここでは「真の値が存在する」という素朴な描像のまま進める。）

The population is the truth, but we can never observe it directly, and we can never take infinitely many readings. We measure, collect a finite amount of data, and average it to estimate the truth. So how close is that average really? The answer is itself a distribution: if we could repeat the whole experiment again and again, how widely would the sample mean scatter around the true value?母集団は真実だが、直接観測することはできず、無限個のデータを取ることもできない。私たちは測定して有限のデータを集め、その平均をとって真実を推測する。では、その平均は本当に真実に近いのだろうか。その「近さ」自体が一つの分布で表せる。もし実験全体を何度も繰り返せたら、標本平均は真の値のまわりにどれくらいの広さでばらつくだろうか。

Concretely: a detector returns the quantity you want plus a random error, and as long as the instrument and conditions are fixed, the spread of that error is the same on every trial. That fixed spread is the parent distribution. Experience tells us that counting for longer, or averaging more repeated readings, pulls the result toward the true value. But infinite time and infinite data are impossible, so we take a finite sample and report its average (the sample mean). Because a finite sample never exactly reproduces the parent, this average never exactly equals the truth. Even identical measurements leave a residual gap (the distribution of the sample mean). Longer integration and more readings shrink that gap; the Central Limit Theorem below explains why, and by how much.具体的な実験に対応させてみよう。測定装置の結果には、知りたい値に常にランダムな誤差が加わる。装置や環境が同じなら、その誤差のばらつきは何度測っても同じ。これが母分布だ。私たちは経験的に、検出時間を長くしたり、繰り返し測って平均をとったりすると結果が真の値に近づくことを知っている。しかし無限の時間も無限のデータも現実には不可能なので、有限の標本を取り、その平均を結果として報告する（標本平均）。有限の標本は母分布を完全には再現しないから、この平均は真の値と必ずしも一致せず、まったく同じ測定を繰り返してもずれが残る（標本平均の分布）。長い検出時間や平均に使う値を増やすことでこのずれを小さくできる。その理由と度合いを、以下の中心極限定理が説明する。

3a — Averaging and the Central Limit Theorem3a — 平均と中心極限定理

Measure one object many times and the readings form a distribution whose shape depends on the experiment (it need not be a bell). Now do something remarkable: take $n$ measurements, average them, and repeat that whole procedure over and over, collecting many averages. Histogram those averages and, whatever the shape of the original distribution, they pile up into a Gaussian. This is the Central Limit Theorem, and the peak of that Gaussian sits at the true value.一つの対象を何度も測ると、測定値はある分布をつくる。その形は実験によって異なる（釣鐘型とは限らない）。ここで驚くべきことが起きる：$n$ 回測って平均をとり、その手続きを何度も繰り返して平均値を多数集める。その平均値をヒストグラムにすると、元の分布の形が何であれ、ガウス分布に積み上がる。これが中心極限定理であり、そのガウス分布のピークは真の値に一致する。

$$g(x)=\frac{1}{\sqrt{2\pi}\,\sigma}\,\exp\!\left[-\frac{(x-\mu)^2}{2\sigma^2}\right]$$

Because the Gaussian is so well understood, it lets us estimate how large $n$ must be to land within a given range of the true value, with a given probability. Try it: pick a decidedly non-normal parent and watch the distribution of the mean turn into a bell as $n$ grows.ガウス分布はよく調べられているので、真の値の所定の範囲内に所定の確率で収めるには $n$ をどれだけ大きくすればよいか、を見積もれる。試してみよう：あえて非正規な母集団を選び、$n$ を増やすと平均の分布が釣鐘型に変わっていく様子を見てほしい。

3c — Expectation and variance3c — 期待値と分散

Now make this quantitative. Call the (unknowable) parent distribution of readings $f(x)$: the probability of getting a reading near $x$, normalised so that $\int f(x)\,dx = 1$. Its expectation value $E$ is the average over infinitely many measurements, and its variance $V$ measures how widely the readings spread around $E$:ここからは定量的に扱う。測定値の（知り得ない）母分布を $f(x)$ とする。$x$ 付近の測定値が得られる確率で、$\int f(x)\,dx = 1$ に規格化しておく。その期待値 $E$ は無限回測定の平均、分散 $V$ は測定値が $E$ のまわりにどれだけ広がるかを表す：

$$E=\int x\,f(x)\,dx,\qquad V=\int (x-E)^2\,f(x)\,dx$$

For a finite set of $k$ readings $x_1,\dots,x_k$ with average $\bar{x}$, these become the familiar sums:$k$ 個の有限の測定値 $x_1,\dots,x_k$（平均 $\bar{x}$）に対しては、おなじみの和になる：

$$\bar{x}=\frac1k\sum_i x_i,\qquad V=\frac1k\sum_i (x_i-\bar{x})^2$$

Why square the deviations? Because each reading lies above or below the mean, so adding the raw deviations gives exactly zero. Squaring makes every term positive (and penalises big misses); it is also easier to handle algebraically than the absolute value. A smaller variance means a more precise measurement. The demo below draws $N$ readings from a parent and reports the sample estimates of $E$ (the mean) and the spread.なぜ偏差を2乗するのか？ 各測定値は平均より上にも下にもずれるので、そのまま足すと合計はちょうど0になる。2乗すれば各項が正になり（大きな外れを強く効かせ）、絶対値より代数的に扱いやすい。分散が小さいほど精密な測定である。下のデモは母集団から $N$ 個の測定値を引き、$E$（平均）とばらつきの標本推定を表示する。

3d — Unbiased variance and the standard error of the mean3d — 不偏分散と平均値の標準誤差

From just $n$ readings, how well can we estimate the parent variance $V$? The honest estimate divides not by $n$ but by $n-1$, giving the unbiased variance $W$. (The difference matters when $n$ is small; for large $n$ it is negligible.) Its expectation over many repeats equals $V$.たった $n$ 個の測定から母分散 $V$ をどれだけ推定できるか。正しい推定は $n$ ではなく $n-1$ で割る。これを不偏分散 $W$ という。（$n$ が小さいとき違いが効く。$n$ が大きければ無視できる。）これを何度も繰り返したときの期待値が $V$ に等しくなる。

$$W=\frac{1}{n-1}\sum_i (x_i-\bar{x})^2$$

Now the key step. Divide $W$ once more by $n$: the result is the variance of the mean $\bar{x}$ itself, exactly the spread of the Gaussian from 3a. Its square root is the standard error $\sigma$, the uncertainty we attach to the average:ここが要だ。$W$ をさらに $n$ で割ると、それは平均値 $\bar{x}$ 自身の分散、まさに 3a のガウス分布の広がりになる。その平方根が標準誤差 $\sigma$ であり、平均につける不確かさである：

$$\sigma=\sqrt{\frac{W}{n}}=\sqrt{\frac{1}{n(n-1)}\sum_i (x_i-\bar{x})^2}\;=\;\frac{s}{\sqrt{n}}$$

Because the mean follows a Gaussian, the standard $\sigma$ probabilities apply: the true value lies within $\bar{x}\pm\sigma$ with probability 68.27 %, within $\bar{x}\pm2\sigma$ with 95.45 %, and within $\bar{x}\pm3\sigma$ with 99.73 %. This $\pm\sigma$ interval is exactly the spread of the sample-mean distribution plotted in 3a.平均はガウス分布に従うので、標準的な $\sigma$ の確率が使える：真の値が $\bar{x}\pm\sigma$ に入る確率は 68.27 %、$\bar{x}\pm2\sigma$ では 95.45 %、$\bar{x}\pm3\sigma$ では 99.73 % になる。この $\pm\sigma$ 区間がまさに 3a で描いた標本平均の分布の広がりだ。

3e — Reporting conventions3e — さまざまな運用

With $\bar{x}$ and $\sigma$ in hand, a result is usually written$\bar{x}$ と $\sigma$ が求まれば、結果は普通こう書く：

$$\text{result}=\bar{x}\pm\sigma$$

Conventionally $\sigma$ is rounded to two significant figures and $\bar{x}$ is quoted down to $\sigma$'s last digit (this is where the significant-figure rules of §01 come from). Some fields instead quote the expanded uncertainty $k\sigma$ (most often $2\sigma$, giving ~95 % coverage), where $k$ is the coverage factor; this is the modern "uncertainty analysis" standard. Conventions vary (some divide by $n$ rather than $n-1$, some scale $\sigma$ differently), so always state which definition you used.慣例として $\sigma$ は有効数字2桁に四捨五入し、$\bar{x}$ は $\sigma$ の最終桁まで示す（§01 の有効数字ルールはここに由来する）。分野によっては拡張不確かさ $k\sigma$（多くは $2\sigma$ で約95%被覆）を示す（$k$ を包含係数と呼ぶ）。これが近年の「不確かさ解析」の標準的作法だ。作法は分野で異なる（$n-1$ でなく $n$ で割る、$\sigma$ を何倍するか等）ので、どの定義で計算したかを必ず明記する。

Concise (parenthesis) notation. A very common shorthand writes the uncertainty in parentheses right after the value, lined up digit-for-digit with the value's last digits:括弧表記（簡潔表記）。非常によく使われる略記で、値の直後に括弧で不確かさを書く。括弧内の数字は値の末尾の桁と桁を揃える：

$$1.2345(67)\equiv1.2345\pm0.0067,\quad 12.34(5)\equiv12.34\pm0.05,\quad m_e=9.1093837015(28)\times10^{-31}\,\text{kg}$$

When the spread itself is the result: $\sigma' = \sqrt{W}$ばらつき自体が結果のとき：$\sigma' = \sqrt{W}$

A different quantity is $\sigma' = \sqrt{W}$ (not divided by $n$). This estimates the spread of the measurand itself (how much an individual reading varies) rather than the uncertainty of the mean. It is the right thing to report when the true value is not the point and the variability is the result, as in quantum measurements, industrial quality control, or survey sampling. There the parent distribution need not be Gaussian, so the neat 68/95 percentages do not directly apply.これとは別の量が $\sigma' = \sqrt{W}$（$n$ で割らない）である。これは平均の不確かさではなく、測定対象そのもののばらつき（個々の測定値がどれだけ変動するか）を推定する。真の値が主眼でなく、ばらつきこそが結果のときに報告すべき量で、量子測定・工業の品質管理・アンケート標本などがそれだ。そこでは母集団がガウスとは限らないので、68/95 の割合はそのままは当てはまらない。

3f — Statistics is not all-powerful3f — 統計は万能ではない

Averaging beats down random error, but not without limit. Reading a millimetre ruler you might estimate to ~0.1 mm by eye; averaging 10,000 readings will not get you to microns. This is not (only) about systematic error. Even with none, the reading resolution itself sets a floor that averaging cannot cross. Always ask what causes the scatter and whether statistics can actually help. And recall the cost: because $\sigma\propto1/\sqrt{n}$, halving the error needs four times as many measurements.平均は偶然誤差を減らすが、無限にではない。ミリ目盛りの定規を目分量で0.1 mmまで読めても、1万回平均してもミクロンには届かない。これは（単に）系統誤差の話ではない。系統誤差がなくても、読み取り分解能そのものが、平均では越えられない下限を与える。ばらつきの原因が何で、統計が本当に効くのかを常に問うべきだ。そして代償も忘れずに：$\sigma\propto1/\sqrt{n}$ なので、誤差を半分にするには測定回数を4倍にしなければならない。

04 — Epilogue04 — むすび

One question, four toolsひとつの問い、4つの道具

This page covered four tools, but they all answer a single question: when you write down a measured value, what exactly are you claiming? §00 classified what can corrupt the claim: a systematic shift that must be found and removed, and a random scatter that statistics can reduce. §01 gave the shorthand: the number of digits you write is itself a statement of uncertainty. §02 made the statement explicit as a ± and derived the rules it obeys inside a calculation: absolute uncertainties for sums, relative ones for products, quadrature when the errors are independent. §03 supplied the engine behind it all: repeated measurement, and the $1/\sqrt{n}$ shrinkage of the standard error.本ページでは4つの道具を扱ったが、それらが答えていた問いは結局ひとつである。測定値を書き記すとき、何を主張していることになるのか。§00 はその主張を狂わせる要因を分類した。見つけて取り除くべき系統的なずれと、統計で減らせる偶然のばらつき。§01 は略記法を与えた。何桁書くかは、それ自体が不確かさの表明である。§02 はその表明を ± として明示し、計算の中で従う規則を導いた。和では絶対誤差、積では相対誤差、独立なら二乗和。§03 はすべての土台となるエンジンを与えた。繰り返し測定と、標準誤差の $1/\sqrt{n}$ での縮小である。

The common thread: a measured value is not a bare number but a number together with a claim about its reliability. Reporting that claim, neither hiding the error nor inflating it, is what turns a reading into a result. Least-squares fitting, signal averaging, and the rest of practical data analysis are all built on this foundation.貫いているのは、「測定値とは裸の数ではなく、信頼度の主張を伴った数である」という一点だ。その主張を、隠しもせず誇張もせずに報告すること。それが読み取り値を「結果」に変える。最小二乗フィットも、信号の積算平均も、実務のデータ解析の残りすべても、この土台の上に組み立てられている。
