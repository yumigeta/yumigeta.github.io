Measurement, Error & Data Analysis測定・誤差・データ解析の基礎

Every measurement carries an uncertainty. Good science is not about avoiding error — it is about estimating, reporting, and handling it correctly. This page builds the working toolkit of the experimentalist: how errors are classified, how many digits a number is allowed to claim (significant figures), how uncertainties propagate through a calculation, and how repeated measurements are analysed statistically. Each idea comes with a hands-on demo.あらゆる測定値は不確かさを伴う。良い科学とは誤差を避けることではなく、それを正しく見積もり・報告し・扱うことである。本ページでは実験者の基本道具をひととおり組み立てる — 誤差の分類、数値が主張してよい桁数（有効数字）、計算を通じた不確かさの伝播、そして繰り返し測定の統計処理。各項目に操作できるデモを添えている。

00 — Types of error00 — 誤差の種類

Systematic vs random — accuracy vs precision系統誤差と偶然誤差 — 正確さと精密さ

Measurement error splits into two fundamentally different kinds. A systematic error shifts every reading the same way (a mis-zeroed scale, an un-subtracted baseline) — it limits accuracy, how close the average sits to the true value. A random error scatters readings unpredictably (electronic noise, counting statistics) — it limits precision, how tightly the readings cluster. Averaging beats down random error but is powerless against a systematic one.測定誤差は本質的に異なる2種類に分かれる。系統誤差はすべての測定値を同じ向きにずらす（ゼロ点のずれ、引き残したベースラインなど） — これは正確さ（accuracy）、すなわち平均が真値にどれだけ近いかを制限する。偶然誤差は測定値を予測できない形でばらつかせる（電子ノイズ、計数統計など） — これは精密さ（precision）、すなわち測定値がどれだけ密に集まるかを制限する。平均をとれば偶然誤差は小さくできるが、系統誤差には無力である。

01 — Significant figures01 — 有効数字

How many digits may you actually trust?その数値は何桁まで信じてよいか

Every measured value contains error, so writing digits below the doubtful one is meaningless — they are just garbage. Ask for the circumference of a circle of diameter 30.0 mm and a calculator happily returns 94.2477796077 mm. But if that last diameter digit is uncertain, the true diameter sits somewhere in 29.95–30.05 mm, and the circumference in 94.09–94.40 mm — already the third digit is in doubt. Everything after it is noise. So scientists adopt a shared convention for how many digits to keep.あらゆる測定値は誤差を含むので、怪しい桁より下を書いても意味がない — ただのデタラメな数字だ。直径 30.0 mm の円の円周を尋ねると、電卓は平気で 94.2477796077 mm と返す。だが最後の直径の桁が不確かなら、真の直径は 29.95〜30.05 mm のどこかにあり、円周は 94.09〜94.40 mm — すでに3桁目が怪しい。それ以降はただのノイズだ。そこで科学者は、何桁残すかの共通ルールを採用する。

The basic convention表記の基本

When you read an instrument you can usually estimate to about 1/10 of the smallest division by eye. That last estimated digit is uncertain, but it still carries real information — so it is worth recording, while anything below it is pure waste. Hence the universal rule:測定器を読むとき、ふつう最小目盛の1/10くらいまで目分量で読み取れる。その最後の桁は不確かだが、おおよそ正しい情報を含むので記録する価値がある — 一方それより下の桁は全くの無駄だ。そこで普遍的なルール：

“The last written digit is informative — but suspect it!”「記載された数値の最後の桁は参考になるが、かなり怪しいと疑え！」

Then how many digits you write tells the reader how far the value can be trusted. A problem arises only above the decimal point: in 123000, are the trailing zeros real or just placeholders? Scientific notation removes the ambiguity:こうすれば、何桁書くかで「どこまで信用できるか」を読み手に伝えられる。困るのは小数点より上の桁だけだ：123000 の末尾のゼロは有効なのか位取りなのか分からない。指数表記（科学的表記法）がこの曖昧さを取り除く：

$$1.23\times10^{5}\ \text{(3 s.f.)},\quad 1.230\times10^{5}\ \text{(4 s.f.)},\quad 1.2300\times10^{5}\ \text{(5 s.f.)}$$

It works for small numbers too: $0.000456 = 4.56\times10^{-4}$ — no need to count zeros. The number of significant figures is counted from the first non-zero digit through the doubtful last digit (leading zeros never count). So $1.230\times10^{5}$ has 4 significant figures; $0.000456$ has 3 (the digits 456).小さな数にも使える：$0.000456 = 4.56\times10^{-4}$ — ゼロを数えなくてよい。有効数字の桁数は、最初の非ゼロ数字から怪しい最後の桁まで数える（先頭のゼロは数えない）。よって $1.230\times10^{5}$ は4桁、$0.000456$ は3桁（456 の部分）である。

The rules for arithmetic四則演算の作法

Addition / subtraction: line the numbers up by place value; the answer can only be trusted down to the highest last-trustworthy place among the inputs, so keep the fewest decimal places. Multiplication / division: place value is irrelevant — only the count of significant figures matters, so the answer keeps the fewest significant figures. In all cases, round just once, at the end. Try it:加算・減算：位を揃えて並べる。結果は入力のうち最後の信頼桁が最も高い位までしか信用できないので、最小の小数位に合わせる。乗算・除算：位は関係なく、有効数字の桁数だけが効くので、結果は最小の有効数字に合わせる。いずれも丸めは最後に1回だけ。試してみよう：

Blue digits are significant; grey digits are placeholders. A result's last kept digit may end in 0 (e.g. $1.1+2.4=3.5$, or a carry making $9.9+0.2=10.1$) — keep that zero, it marks where the doubt sits. Subtraction can be brutal: $1.2345-1.2300=0.0045$ turns 5- and 6-figure inputs into a 2-figure answer (catastrophic cancellation). Round only the final answer.青字が有効数字、グレーが位取りのゼロ。結果の最後の桁が 0 になることもある（例 $1.1+2.4=3.5$、繰り上がりで $9.9+0.2=10.1$）— その 0 は「ここに疑いがある」ことを示すので残す。引き算は厳しい：$1.2345-1.2300=0.0045$ は5桁・6桁の入力を2桁の答えに変えてしまう（桁落ち）。丸めは最終結果だけ。

Constants and defined values数学定数・定義値の扱い

Formulas often contain non-measured numbers. Mathematical constants ($\pi$, $e$), plain integers in a formula (the "2" in $2\pi r$), exact counts (1, 2, 3 … particles), and defined values all carry infinitely many significant figures and never limit the result. The speed of light, $c=299{,}792{,}458$ m/s, is defined exactly — treat it as infinite, not 9-figure. (Since 2019 the Avogadro constant is likewise a defined value; older texts list it as a measured, finite-precision number.)公式には測定値でない数も現れる。数学定数（$\pi$, $e$）、公式中のただの整数（$2\pi r$ の「2」）、はっきり数えられる個数（粒子1, 2, 3個…）、そして定義値は、すべて有効数字無限桁として扱い、結果の桁数を制限しない。光速 $c=299{,}792{,}458$ m/s は定義値なので、9桁ではなく無限桁として扱う。（2019年以降はアボガドロ定数も定義値。古い教科書では有限精度の測定値として載っている。）

A practical shortcut楽する工夫

You never need the full infinite expansion of a constant. Carrying one or two guard digits beyond the target precision is enough — extra digits change nothing. There is no point typing a 12-digit value of $\pi$ into your calculator. (For exact-half ties some fields use round-half-to-even / banker's rounding — round so the preceding digit becomes even, e.g. $2.5\to2$, $3.5\to4$ — to avoid the slight upward bias of always rounding 5 up. Ordinary rounding is fine otherwise.)定数の無限桁をまるごと使う必要はない。目標精度より1〜2桁多く持っておけば十分で、それ以上は結果を変えない。$\pi$ を12桁も電卓に打ち込むのは無駄だ。（ちょうど 5 の端数には、分野によって五捨五入（偶数丸め）を使う — 直前の桁が偶数になるように丸める。例 $2.5\to2$, $3.5\to4$ — 常に切り上げる四捨五入のわずかな上振れを避けるためだ。普通はふつうの四捨五入で構わない。）

How well-founded are these rules, really?これらの作法は本当に正しいのか

Honestly — not very. They quietly assume the last digit is uncertain by about $\pm0.5$, but a real measurement's last digit can be off by 2 or 3. Adding more than ten such numbers lets the error creep up a whole place; multiplication and division routinely shift the last digit by one or two. And two values with the same 3 figures, like 1.00 and 9.00, carry very different relative errors, which matters in products. Worst of all, the rules say nothing about $\sqrt{\ }$, $\ln$, $\sin$, … So where do they actually come from, and when do they fail? Both questions have the same answer: error propagation.正直なところ、あまり正しくない。これらは末尾桁の誤差を暗黙に $\pm0.5$ 程度と仮定しているが、実際の測定では末尾が 2〜3 ずれることもある。10個以上を足せば誤差は1つ上の桁まで及び得るし、乗除では末尾桁が普通に1〜2ずれる。同じ3桁でも 1.00 と 9.00 では相対誤差がまるで違い、これは積で効く。極めつけに、$\sqrt{\ }$・$\ln$・$\sin$ などには何も言えない。では、これらの作法はどこから来て、いつ破綻するのか。答えはどちらも同じ — 誤差伝播である。

A value written to some number of digits is an implicit uncertainty claim: 12.3 means about $12.3\pm0.05$. "How many digits may I keep?" is really "how big is the uncertainty of the result?", and that is fixed by how the input uncertainties propagate. The per-operation formulas — absolute uncertainties combined for $+$ and $-$, relative ones for $\times$, $\div$ and powers, and the rules for $\sqrt{\ }$, $\ln$ and $\exp$ — are collected and derived in §02.ある桁数まで書かれた値は、暗黙の不確かさの主張である：12.3 はおよそ $12.3\pm0.05$ を意味する。「何桁残せるか」とは実は「結果の不確かさはどれくらいか」であり、それは入力の不確かさがどう伝播するかで決まる。演算ごとの公式 — $+$・$-$ では絶対不確かさ、$\times$・$\div$・べき乗では相対不確かさ、そして $\sqrt{\ }$・$\ln$・$\exp$ の規則 — は §02 にまとめて導出してある。

So significant-figure rules are just error propagation done in your head — a convenient but crude stand-in, fine for a quick sanity check but no substitute for a real uncertainty. Modern practice ("uncertainty analysis") quotes the uncertainty explicitly instead; significant-figure bookkeeping is increasingly a high-school / exam convention. When it matters, compute the uncertainty directly (§02) and write it down (§02–03).つまり有効数字のルールとは、頭の中でやる誤差伝播にすぎない — 便利だが粗い代用品で、手早い確認には使えても本当の不確かさの代わりにはならない。現代の作法（不確かさ解析）では不確かさを明示的に併記し、有効数字の桁合わせは次第に高校・受験向けのローカルルールになりつつある。重要なときは不確かさを直接計算し（§02）、そして併記すること（§02〜03）。

02 — Propagation of uncertainty02 — 誤差の伝播

How input uncertainties combine in a result入力の不確かさが結果でどう合成されるか

You rarely measure the quantity you want directly. Often you compute it from several other measurements — an indirect measurement $X=f(a,b,c)$ — and you must carry the errors of $a,b,c$ through to $X$. For a simple $f$ you could just nudge each input within its error and read off the largest and smallest $X$ (exactly what the Monte-Carlo panel below does). The general shortcut comes from a first-order Taylor expansion:求めたい量を直接測れることはまれだ。多くは複数の測定から計算する — 間接測定 $X=f(a,b,c)$ — ので、$a,b,c$ の誤差を $X$ まで運ぶ必要がある。$f$ が単純なら、各入力を誤差の範囲で動かして $X$ の最大・最小を読めばよい（下のモンテカルロパネルがまさにそれだ）。一般的な近道は1次のテイラー展開から得られる：

$$f(a+\Delta a,\,b+\Delta b,\,c+\Delta c)\simeq f(a,b,c)+\frac{\partial f}{\partial a}\Delta a+\frac{\partial f}{\partial b}\Delta b+\frac{\partial f}{\partial c}\Delta c$$

Worst case (maximum error). If every error could conspire to push $X$ the same way, take absolute values so the terms always reinforce:最悪値（最大誤差）。すべての誤差が $X$ を同じ向きに押すよう共謀し得るなら、項が必ず強め合うように絶対値をとる：

$$\Delta X=\left|\frac{\partial f}{\partial a}\right|\Delta a+\left|\frac{\partial f}{\partial b}\right|\Delta b+\left|\frac{\partial f}{\partial c}\right|\Delta c$$

Statistical case (quadrature). When the errors are independent and random, they more often partly cancel than fully reinforce. The honest estimate then adds them in quadrature — the smaller, realistic uncertainty used throughout this page:統計的な場合（二乗和）。誤差が独立でランダムなら、完全に強め合うより部分的に打ち消し合うことの方が多い。その場合の正直な見積もりは二乗和で合成する — 本ページで通して使う、より小さく現実的な不確かさだ：

$$\delta f=\sqrt{\sum_i\left(\frac{\partial f}{\partial x_i}\right)^{\!2}\delta x_i^{\,2}}$$

The worst case is an upper bound; quadrature is what you expect on average. Either way the same shortcuts fall out: for sums and differences the absolute uncertainties combine; for products, quotients and powers the relative ones do (a power $x^n$ multiplies the relative uncertainty by $|n|$, a logarithm turns a relative error into an absolute one).最悪値は上限、二乗和は平均的に期待される値だ。どちらでも同じ近道が出てくる：和・差では絶対不確かさが、積・商・べき乗では相対不確かさが合成される（べき乗 $x^n$ は相対不確かさを $|n|$ 倍し、対数は相対誤差を絶対誤差に変える）。

Why independent errors add in quadrature — and correlated ones add linearlyなぜ独立なら二乗和、相関があれば線形和になるのか

Write the deviation of the $i$-th result from the Taylor expansion, then square it and average over $N$ measurements. The square gives square terms plus cross terms:$i$ 番目の結果のずれをテイラー展開で書き、2乗して $N$ 回の測定で平均する。2乗すると平方項と交差項が出る：

$$\sigma_X^2=\sum_i\left(\frac{\partial f}{\partial x_i}\right)^{\!2}\sigma_{x_i}^2\;+\;\underbrace{\sum_{i\neq j}\frac{\partial f}{\partial x_i}\frac{\partial f}{\partial x_j}\,\sigma_{x_i x_j}}_{\text{cross terms (covariances)}}$$

Square terms are always positive and never cancel. The cross terms carry the covariances $\sigma_{x_i x_j}$. If the variables are independent and random, each cross term is as likely positive as negative, so they sum to zero (more perfectly as $N$ grows) — leaving the clean quadrature sum of variances. If instead the variables are fully correlated (an error in one always drags the others the same way), the cross terms survive and reinforce, and the root-sum collapses back into the linear worst-case sum. Real cases lie between these limits — which is why covariances must be kept when measurements are not independent (e.g. two masses read off the same mis-calibrated balance).平方項は常に正で打ち消さない。交差項は共分散 $\sigma_{x_i x_j}$ を担う。変数が独立でランダムなら、各交差項は正にも負にも等しくなりやすく、合計は0に近づく（$N$ が大きいほど完全に）— こうして二乗和だけが残る。逆に変数が完全に相関していれば（一方の誤差が常に他方を同じ向きに引きずる）、交差項は生き残って強め合い、平方和は線形の最悪値和に戻る。実際はこの中間にあり、だから測定が独立でないとき（同じ狂った天秤で読んだ2つの質量など）は共分散を残す必要がある。

Quadrature means a small uncertainty contributes almost nothing once a larger one is present, so effort is best spent on the dominant term.ほぼ線形な式では解析式とモンテカルロの値は一致する — 同じ不確かさへの独立な2つの経路だ。二乗和では、大きな不確かさがあると小さなものはほとんど効かないので、支配的な項に労力を割くのが最善である。

Why isn't the histogram always a bell curve?ヒストグラムが必ずしも釣鐘型にならないのは？

The analytic formula is a first-order (linear) approximation: it replaces $f$ by its tangent over the $\pm\delta$ range and assumes the result is Gaussian. For a nonlinear $f$ — try x*sin(y) — pushing the uncertainties up makes the true (Monte-Carlo) distribution skewed and non-normal, and the green Normal curve no longer fits. The effect is strongest where the slope $\partial f/\partial x_i$ nearly vanishes (e.g. $y$ near $\pi/2$ for $\sin y$), and where $f$ is a product of comparable random factors. Unlike a sum of many terms, a 2-variable $f$ has no reason to be normal (no Central Limit Theorem here). Shrink the $\delta$ sliders and the linear approximation recovers — the histogram tightens back onto the green curve and the agreement rises.解析式は一次（線形）近似で、$\pm\delta$ の範囲で $f$ を接線に置き換え、結果がガウス分布だと仮定している。非線形な $f$（例：x*sin(y)）で不確かさを大きくすると、真の（モンテカルロ）分布は歪んで非正規になり、緑の正規曲線は合わなくなる。効果が最も強いのは、傾き $\partial f/\partial x_i$ がほぼ消える点（$\sin y$ なら $y\approx\pi/2$ 付近）や、同程度の大きさの確率変数どうしの積になっている場合だ。多数の項の和と違い、2変数の $f$ が正規分布になる理由はない（ここでは中心極限定理は効かない）。$\delta$ スライダーを小さくすると線形近似が回復し、ヒストグラムは緑曲線に締まり、一致度も上がる。

Pre-computed: products, powers and logarithmsあらかじめ計算：積・べき乗・対数

Doing the partial derivatives every time is tedious, so pre-compute the common form. Most physics formulas look like $X=a^{l}b^{m}c^{n}$. Feed it through the propagation formula and divide by $|X|$, and the absolute mess collapses into a tidy sum of relative errors:毎回偏微分するのは面倒なので、よく出る形をあらかじめ計算しておく。多くの物理量は $X=a^{l}b^{m}c^{n}$ の形だ。これを伝播式に通して $|X|$ で割ると、絶対誤差の煩雑さが相対誤差のすっきりした和にまとまる：

$$\frac{\Delta X}{|X|}=|l|\frac{\Delta a}{|a|}+|m|\frac{\Delta b}{|b|}+|n|\frac{\Delta c}{|c|}$$

So a squared quantity contributes twice its relative error, a square root half, and it makes no difference whether a factor multiplies or divides. Logarithms are the other handy case: for $X=\ln a$ the propagation formula gives $\Delta X=\Delta a/|a|$ — a relative error becomes an absolute one. (These are exactly the §01 shortcuts, now derived.)2乗の量は相対誤差の2倍、平方根なら半分を寄与し、掛けるか割るかは関係ない。対数はもう一つの便利な例で、$X=\ln a$ なら伝播式から $\Delta X=\Delta a/|a|$ — 相対誤差が絶対誤差になる。（これらは §01 の近道を、いま導出したものだ。）

Reference: propagation formulas for the basic operations早見：基本演算の誤差伝播公式

Addition / subtraction — absolute uncertainties combine (this is why you keep the fewest decimal places):加算・減算 — 絶対不確かさが合成される（だから最小の小数位に合わせる）：

$$z=x\pm y\;\Rightarrow\;\delta z=\sqrt{(\delta x)^2+(\delta y)^2}$$

Multiplication / division — relative uncertainties combine (this is why you keep the fewest significant figures):乗算・除算 — 相対不確かさが合成される（だから最小の有効数字に合わせる）：

$$z=xy\ \text{or}\ \frac{x}{y}\;\Rightarrow\;\frac{\delta z}{|z|}=\sqrt{\left(\frac{\delta x}{x}\right)^2+\left(\frac{\delta y}{y}\right)^2}$$

Powers and roots — the relative uncertainty is multiplied by the exponent:べき乗・根 — 相対不確かさは指数倍される：

$$z=x^{n}\;\Rightarrow\;\frac{\delta z}{|z|}=|n|\,\frac{\delta x}{|x|}$$

Scaling, logarithm and exponential — handy special cases:定数倍・対数・指数 — よく使う特殊例：

$$z=c\,x\Rightarrow\delta z=|c|\,\delta x,\qquad z=\ln x\Rightarrow\delta z=\frac{\delta x}{|x|},\qquad z=e^{x}\Rightarrow\frac{\delta z}{|z|}=\delta x$$

Every line is the single general rule $(\delta z)^2=\sum_i(\partial z/\partial x_i)^2(\delta x_i)^2$ evaluated for that function — the quadrature (independent/random) version. For a worst-case bound, drop the squares and add the absolute terms instead.どの行も、一般則 $(\delta z)^2=\sum_i(\partial z/\partial x_i)^2(\delta x_i)^2$ を各関数について評価したもの — 二乗和（独立・ランダム）版である。最悪値の上限が欲しいなら、2乗を外して絶対値の項をそのまま足せばよい。

When the terms are repeated measurements統計を考慮する

The worst-case sum is right when you accumulate independent pieces — measuring a length in several segments and adding them. But adding up repeated measurements of the same quantity to form an average is different: those readings scatter both above and below, so their random errors tend to cancel rather than pile up. (A systematic error does accumulate, but dividing by $n$ brings it back to one reading's worth.) How fast the random part shrinks with the number of measurements is the subject of the next module.最悪値の和が正しいのは、独立な部分を蓄積するとき — 長さを何区間かに分けて測り足し合わせる場合だ。しかし同じ量の繰り返し測定を足して平均をとるのは別物だ：それらの測定値は上にも下にもばらつくので、偶然誤差は積み重なるより打ち消し合う傾向がある。（系統誤差は蓄積するが、$n$ で割れば1回分の測定に戻る。）偶然誤差が測定回数とともにどれだけ速く縮むかが、次のモジュールの主題である。

How to write the result誤差の表記法

Once you have an uncertainty, don't quote it to many digits — it only needs to show where the doubt sits. Keep the error to its top significant figure (carry a second figure if it rounds to a leading 1, or for statistical results), and quote the value down to the same place as the error's last digit. Round only at the end; two digits in intermediate steps is plenty.不確かさが求まったら、桁を長々と書かない — どこに疑いがあるかを示せれば十分だ。誤差は最上位の1桁に丸め（先頭が1に丸まる場合や統計処理の値では2桁残す）、測定値は誤差の末尾と同じ位まで書く。丸めは最後だけ、途中は2桁で十分だ。

$$\delta=0.0732\to0.07:\ \ 3.54\pm0.07\qquad \delta=0.00953\to0.010:\ \ 3.537\pm0.010\qquad \delta=0.127\to0.13:\ \ 3.54\pm0.13$$

For readability, prefer the factored form $(1.23\pm0.05)\times10^{5}$ over $123000\pm5000$.読みやすさのため、$123000\pm5000$ より $(1.23\pm0.05)\times10^{5}$ の括り出し表記が望ましい。

Concise (parenthesis) notation. A very common shorthand writes the uncertainty in parentheses right after the value: the parenthesised digits are the uncertainty in the last digits of the quoted value, lined up digit-for-digit. So括弧表記（簡潔表記）。非常によく使われる略記で、値の直後に括弧で不確かさを書く：括弧内の数字は、表示した値の末尾の桁の不確かさを、桁を揃えて表す。すなわち

$$1.2345(67)\;\equiv\;1.2345\pm0.0067,\qquad 12.34(5)\;\equiv\;12.34\pm0.05$$

— the parenthesised number occupies the same decimal places as the value's final digits. It combines naturally with powers of ten; for example the electron mass— 括弧の数字は、値の末尾の桁と同じ小数位を占める。10のべき乗とも自然に組み合わさる。例えば電子の質量は

$$m_e=9.1093837015(28)\times10^{-31}\ \text{kg}\;\equiv\;(9.1093837015\pm0.0000000028)\times10^{-31}\ \text{kg}$$

means the last two digits, 15, are uncertain by about $\pm28$. Conventions vary by field, so always state which you used — and always quote the uncertainty, so the next calculation can propagate it.は、末尾の2桁 15 が約 $\pm28$ 怪しいことを意味する。作法は分野で異なるのでどれを使ったか必ず明記し、そして必ず不確かさを併記する — 次の計算でそれを伝播できるように。

Worked example: Beer's law実例：ビールの法則

The molar absorptivity from Beer's law is $\varepsilon=A/(l\,c)$. With $A=0.172807\,(\pm0.000008)$, $l=1.0\,(\pm0.1)$ cm, and $c=13.7\,(\pm0.3)$ mol/L, the relative errors combine in quadrature:ビールの法則によるモル吸光係数は $\varepsilon=A/(l\,c)$。$A=0.172807\,(\pm0.000008)$、$l=1.0\,(\pm0.1)$ cm、$c=13.7\,(\pm0.3)$ mol/L とすると、相対誤差が二乗和で合成される：

$$\frac{\delta\varepsilon}{\varepsilon}=\sqrt{\left(\frac{0.000008}{0.172807}\right)^{\!2}+\left(\frac{0.1}{1.0}\right)^{\!2}+\left(\frac{0.3}{13.7}\right)^{\!2}}\approx0.102\;\Rightarrow\;\varepsilon=0.013\pm0.001$$

The $\pm0.1$ cm path length dominates entirely (a 10 % relative error), so a better cuvette — not a better spectrophotometer — is what would improve the result. Load the ε = A/(l·c) preset above (with $x=A$, $y=l$, $z=c$) and the variance-share bars show exactly this.$\pm0.1$ cm の光路長が完全に支配し（相対誤差10%）、結果を改善するのは分光光度計ではなく良いセル（キュベット）だと分かる。上の ε = A/(l·c) プリセット（$x=A$, $y=l$, $z=c$）を読み込むと、分散寄与の棒がまさにこれを示す。

Cautions注意点

Propagation assumes each relative uncertainty is small (the linear approximation — see the histogram note above). If you can get the uncertainty directly, by repeating the whole experiment and watching the scatter, prefer that to propagating (§03). And remember: a calculation never reduces uncertainty — only better measurements do. In complex cases the estimate can also go wrong through unsuspected covariances, a mis-specified model, or arithmetic slips.伝播は各相対誤差が小さいことを前提とする（線形近似 — 上のヒストグラム注記を参照）。実験全体を繰り返してばらつきから直接不確かさを得られるなら、伝播よりそちらを優先する（§03）。そして忘れてはいけない：計算で不確かさは決して減らない — 減らせるのはより良い測定だけだ。複雑な場合には、見落とした共分散、モデルの誤設定、計算ミスによって見積もりが狂うこともある。

03 — Statistical processing of measurements03 — 測定値の統計処理

Does averaging really reduce the error?平均を取れば誤差は減るのか？

A random error scatters readings around the true value. Take many measurements and average them, and you expect to land close to that true value — but how close, and how should the confidence be reported? That is the whole question of this module. (Strictly we never observe the true value itself — only error-laden readings — and for some phenomena, such as quantum measurements, no single true value even exists. We will nonetheless keep the intuitive picture that a true value is out there.)偶然誤差は測定値を真の値のまわりにばらつかせる。何度も測って平均すれば真の値に近づくはずだが — どれくらい近いのか、そして確からしさをどう表現すればよいのか。これが本モジュールの主題である。（厳密には我々は真の値そのものを観測できず、誤差を含む測定値しか得られない。量子測定のように、そもそも単一の真の値が存在しない対象もある。ここでは「真の値が存在する」という素朴な描像のまま進める。）

3a — Averaging and the Central Limit Theorem3a — 平均と中心極限定理

Measure one object many times and the readings form a distribution — and its shape depends on the experiment (it need not be a bell). Now do something remarkable: take $n$ measurements, average them, and repeat that whole procedure over and over, collecting many averages. Histogram those averages and — whatever the shape of the original distribution — they pile up into a Gaussian. This is the Central Limit Theorem, and the peak of that Gaussian sits at the true value.一つの対象を何度も測ると、測定値はある分布をつくる — その形は実験によって異なる（釣鐘型とは限らない）。ここで驚くべきことが起きる：$n$ 回測って平均をとり、その手続きを何度も繰り返して平均値を多数集める。その平均値をヒストグラムにすると — 元の分布の形が何であれ — ガウス分布に積み上がる。これが中心極限定理であり、そのガウス分布のピークは真の値に一致する。

$$g(x)=\frac{1}{\sqrt{2\pi}\,\sigma}\,\exp\!\left[-\frac{(x-\mu)^2}{2\sigma^2}\right]$$

Because the Gaussian is so well understood, it lets us estimate how large $n$ must be to land within a given range of the true value, with a given probability. Try it: pick a decidedly non-normal parent and watch the distribution of the mean turn into a bell as $n$ grows.ガウス分布はよく調べられているので、真の値の所定の範囲内に所定の確率で収めるには $n$ をどれだけ大きくすればよいか、を見積もれる。試してみよう：あえて非正規な母集団を選び、$n$ を増やすと平均の分布が釣鐘型に変わっていく様子を見てほしい。

3b — Expectation and variance3b — 期待値と分散

Call the (unknowable) parent distribution of readings $f(x)$ — the probability of getting a reading near $x$, normalised so that $\int f(x)\,dx = 1$. Its expectation value $E$ is the average over infinitely many measurements, and its variance $V$ measures how widely the readings spread around $E$:測定値の（知り得ない）母分布を $f(x)$ とする — $x$ 付近の測定値が得られる確率で、$\int f(x)\,dx = 1$ に規格化しておく。その期待値 $E$ は無限回測定の平均、分散 $V$ は測定値が $E$ のまわりにどれだけ広がるかを表す：

$$E=\int x\,f(x)\,dx,\qquad V=\int (x-E)^2\,f(x)\,dx$$

For a finite set of $k$ readings $x_1,\dots,x_k$ with average $\bar{x}$, these become the familiar sums:$k$ 個の有限の測定値 $x_1,\dots,x_k$（平均 $\bar{x}$）に対しては、おなじみの和になる：

$$\bar{x}=\frac1k\sum_i x_i,\qquad V=\frac1k\sum_i (x_i-\bar{x})^2$$

Why square the deviations? Because each reading lies above or below the mean, so adding the raw deviations gives exactly zero. Squaring makes every term positive (and penalises big misses); it is also easier to handle algebraically than the absolute value. A smaller variance means a more precise measurement. The demo below draws $N$ readings from a parent and reports the sample estimates of $E$ (the mean) and the spread.なぜ偏差を2乗するのか？ 各測定値は平均より上にも下にもずれるので、そのまま足すと合計はちょうど0になる。2乗すれば各項が正になり（大きな外れを強く効かせ）、絶対値より代数的に扱いやすい。分散が小さいほど精密な測定である。下のデモは母集団から $N$ 個の測定値を引き、$E$（平均）とばらつきの標本推定を表示する。

3c — Unbiased variance and the standard error of the mean3c — 不偏分散と平均値の標準誤差

From just $n$ readings, how well can we estimate the parent variance $V$? The honest estimate divides not by $n$ but by $n-1$ — the unbiased variance $W$. (The difference matters when $n$ is small; for large $n$ it is negligible.) Its expectation over many repeats equals $V$.たった $n$ 個の測定から母分散 $V$ をどれだけ推定できるか。正しい推定は $n$ ではなく $n-1$ で割る — 不偏分散 $W$ である。（$n$ が小さいとき違いが効く。$n$ が大きければ無視できる。）これを何度も繰り返したときの期待値が $V$ に等しくなる。

$$W=\frac{1}{n-1}\sum_i (x_i-\bar{x})^2$$

Now the key step. Divide $W$ once more by $n$: the result is the variance of the mean $\bar{x}$ itself — exactly the spread of the Gaussian from 3a. Its square root is the standard error $\sigma$, the uncertainty we attach to the average:ここが要だ。$W$ をさらに $n$ で割ると、それは平均値 $\bar{x}$ 自身の分散 — まさに 3a のガウス分布の広がり — になる。その平方根が標準誤差 $\sigma$ であり、平均につける不確かさである：

$$\sigma=\sqrt{\frac{W}{n}}=\sqrt{\frac{1}{n(n-1)}\sum_i (x_i-\bar{x})^2}\;=\;\frac{s}{\sqrt{n}}$$

Because the mean follows a Gaussian, the standard $\sigma$ probabilities apply: the true value lies within $\bar{x}\pm\sigma$ with probability 68.27 %, within $\bar{x}\pm2\sigma$ with 95.45 %, and within $\bar{x}\pm3\sigma$ with 99.73 %. The amber band in the demo above is exactly this $\pm\sigma$ interval, and it narrows as $1/\sqrt{n}$.平均はガウス分布に従うので、標準的な $\sigma$ の確率が使える：真の値が $\bar{x}\pm\sigma$ に入る確率は 68.27 %、$\bar{x}\pm2\sigma$ では 95.45 %、$\bar{x}\pm3\sigma$ では 99.73 % になる。上のデモの橙の帯がまさにこの $\pm\sigma$ 区間で、$1/\sqrt{n}$ で狭まっていく。

3d — Reporting conventions3d — さまざまな運用

With $\bar{x}$ and $\sigma$ in hand, a result is usually written$\bar{x}$ と $\sigma$ が求まれば、結果は普通こう書く：

$$\text{result}=\bar{x}\pm\sigma$$

Conventionally $\sigma$ is rounded to two significant figures and $\bar{x}$ is quoted down to $\sigma$'s last digit (this is where the significant-figure rules of §01 come from). Some fields instead quote the expanded uncertainty $k\sigma$ — most often $2\sigma$, giving ~95 % coverage — where $k$ is the coverage factor; this is the modern "uncertainty analysis" standard.慣例として $\sigma$ は有効数字2桁に四捨五入し、$\bar{x}$ は $\sigma$ の最終桁まで示す（§01 の有効数字ルールはここに由来する）。分野によっては拡張不確かさ $k\sigma$ — 多くは $2\sigma$ で約95%被覆 — を示す。$k$ を包含係数と呼ぶ。これが近年の「不確かさ解析」の標準的作法である。

A different quantity is $\sigma' = \sqrt{W}$ (not divided by $n$). This estimates the spread of the measurand itself — how much an individual reading varies — rather than the uncertainty of the mean. It is the right thing to report when the true value is not the point: the variability is the result, as in quantum measurements, industrial quality control, or survey sampling. There, the parent distribution need not be Gaussian, so the neat 68/95 percentages do not directly apply.これとは別の量が $\sigma' = \sqrt{W}$（$n$ で割らない）である。これは平均の不確かさではなく、測定対象そのもののばらつき — 個々の測定値がどれだけ変動するか — を推定する。真の値が主眼でないときに報告すべき量で、量子測定、工業の品質管理、アンケート標本のように「ばらつきこそが結果」の場合に使う。そこでは母集団がガウスとは限らないので、68/95 の割合はそのままは当てはまらない。

Conventions vary by field — some divide by $n$ rather than $n-1$, some scale $\sigma$ differently — so always state which definition you used.作法は分野によって異なり（$n-1$ ではなく $n$ で割る、$\sigma$ を何倍するか等）、どの定義で計算したかを必ず明記することが大切である。

3e — Statistics is not all-powerful3e — 統計は万能ではない

Averaging beats down random error, but not without limit. Reading a millimetre ruler you might estimate to ~0.1 mm by eye; averaging 10,000 readings will not get you to microns. This is not (only) about systematic error — even with none, the reading resolution itself sets a floor that averaging cannot cross. Always ask what causes the scatter and whether statistics can actually help. And recall the cost: because $\sigma\propto1/\sqrt{n}$, halving the error needs four times as many measurements.平均は偶然誤差を減らすが、無限にではない。ミリ目盛りの定規を目分量で0.1 mmまで読めても、1万回平均してもミクロンには届かない。これは（単に）系統誤差の話ではない — 系統誤差がなくても、読み取り分解能そのものが、平均では越えられない下限を与える。ばらつきの原因が何で、統計が本当に効くのかを常に問うべきだ。そして代償も忘れずに：$\sigma\propto1/\sqrt{n}$ なので、誤差を半分にするには測定回数を4倍にしなければならない。

3f — Extension: least-squares fitting3f — 発展：最小二乗フィット

Suppose your data points seem to fall along a straight line, but scattered by noise. Which line is best? Pick any candidate line $y=ax+b$. For each measured point, the line predicts a value $a x_i + b$, and the residual $r_i = y_i - (a x_i + b)$ is the vertical gap between the point and the line — how badly the line misses that point. A good line makes all the gaps small at once.データ点がほぼ直線上に並んでいるが、ノイズで散らばっているとしよう。どの直線が最良だろうか？ 候補の直線 $y=ax+b$ を1本選ぶ。各測定点について直線は値 $a x_i + b$ を予測し、残差 $r_i = y_i - (a x_i + b)$ は点と直線の縦方向のずれ — その点をどれだけ外しているか — を表す。良い直線はすべてのずれを同時に小さくする。

We can't just add the residuals — positive and negative gaps would cancel, making a terrible line look perfect. Instead we square each gap (always positive, and big misses count extra) and add them up. The least-squares line is the single $(a,b)$ that makes this total, $\sum_i r_i^2$, as small as possible. In the demo the grey stems are these residuals — the fit settles where their squared lengths add to the minimum.残差をそのまま足すことはできない — 正と負のずれが打ち消し合い、ひどい直線が完璧に見えてしまう。そこで各ずれを二乗し（常に正で、大きな外れほど強く効く）、それらを合計する。最小二乗直線とは、この合計 $\sum_i r_i^2$ を最小にする唯一の $(a,b)$ である。デモの灰色の縦線がまさにこの残差で、二乗した長さの合計が最小になる位置に直線が落ち着く。

Step by step: from "smallest squared error" to the formulasステップごとに：「二乗誤差最小」から公式へ

1. Write the total squared error as a function of the line's two unknowns:1. 二乗誤差の合計を、直線の2つの未知数の関数として書く：

$$S(a,b)=\sum_i \big(y_i - a x_i - b\big)^2$$

2. $S$ is smallest where it is flat in every direction — so its slopes with respect to $a$ and to $b$ are both zero ($\partial S/\partial a = 0$, $\partial S/\partial b = 0$). That gives two linear equations.2. $S$ はあらゆる方向に平らな点で最小になる — つまり $a$ と $b$ それぞれに対する傾きがともにゼロ（$\partial S/\partial a = 0$, $\partial S/\partial b = 0$）。これで2本の1次方程式が得られる。

3. Solving them gives a single answer (here $N$ is the number of points):3. これを解くと唯一の答えが得られる（$N$ は点の数）：

$$a=\frac{N\sum x_i y_i-\sum x_i\sum y_i}{N\sum x_i^2-\left(\sum x_i\right)^2},\qquad b=\bar{y}-a\,\bar{x}$$

The intercept formula $b=\bar y - a\bar x$ just says the best line always passes through the data's centre of mass $(\bar x,\bar y)$.切片の式 $b=\bar y - a\bar x$ は、最良の直線が必ずデータの重心 $(\bar x,\bar y)$ を通ることを意味する。

What the numbers mean. The slope $a$ is how much $y$ changes per unit of $x$ (often the physical quantity you want); the intercept $b$ is $y$ at $x=0$. Because the data are noisy, $a$ and $b$ are themselves uncertain — the fit also reports their error bars $\delta a,\delta b$. The $R^2$ value (0 to 1) is the fraction of the variation in $y$ that the line explains: $R^2=1$ is a perfect straight-line fit, while $R^2\approx 0$ means the line is no better than a flat average. Add scattered points in the demo and watch $R^2$ drop and the error bars widen.数値の意味。傾き $a$ は $x$ が1増えるごとの $y$ の変化（多くの場合これが求めたい物理量）、切片 $b$ は $x=0$ での $y$。データにノイズがあるため $a$ と $b$ 自体も不確かで、フィットはその誤差棒 $\delta a,\delta b$ も返す。$R^2$（0〜1）は、直線が $y$ のばらつきのうちどれだけを説明できるかの割合：$R^2=1$ は完全な直線フィット、$R^2\approx 0$ は平らな平均と大差ないことを意味する。デモで点を散らして加え、$R^2$ が下がり誤差棒が広がる様子を見てみよう。
